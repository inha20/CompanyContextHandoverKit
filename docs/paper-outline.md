# 논문화 아웃라인 (초안)

**가제:** 구조화된 인수인계 문서를 이용한 폐쇄형 LLM의 기업 맥락 주입 및 유지 기법
*(Structured Handover Documents for Injecting and Maintaining Enterprise Context in Closed LLMs)*

## 연구 질문
- RQ1. 구조화된 인수인계 폴더는 비구조화 프롬프트보다 업무 응답의 정확성을 높이는가?
- RQ2. "문서에 없으면 모른다고 답하라" 규칙은 환각(근거 없는 응답)을 얼마나 줄이는가?
- RQ3. 낡은 맥락은 오류에 얼마나 기여하며, 변동성 기반 갱신 주기가 이를 줄이는가?
- RQ4. 세션 종료 시 AI가 제안하는 갱신안은 사람이 만든 갱신과 비교해 얼마나 정확한가?

## 방법
1. 가상 기업(제조/서비스 각 1개)의 인수인계 폴더와 업무 시나리오 40~60개 구성
2. 조건 비교
   - A: 맥락 없음
   - B: 비구조화 긴 프롬프트
   - C: 구조화 폴더(본 방법)
   - D: C + 낡음 검사/갱신 루프
3. 평가 지표: 사실 정확도, 규칙 위반율, 근거 인용률, 모름 응답 적절성, 응답 일관성(세션 간)
4. 평가자: 사람 2인 이상 + 평가자 간 일치도(Cohen's κ), 보조로 LLM 판정
5. 다중 모델(최소 2개) 반복 실험으로 모델 의존성 확인

## 예상 기여
- 재학습 없이 맥락을 이식·갱신하는 **파일 기반 프로토콜**
- 변동성 분류와 낡음 검사 규칙
- 공개 가능한 가상 기업 벤치마크와 평가 스크립트

## 장 구성
1. 서론 · 2. 관련 연구(RAG, 프롬프트 엔지니어링, 지식 관리, 온보딩) · 3. 방법
4. 실험 설계 · 5. 결과 · 6. 논의(보안, 확장성, 한계) · 7. 결론
